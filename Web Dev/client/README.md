# AAA - Assembly Animation Automation

This project allows users to upload `.iam` and `.ipt` files, generate assembly animations using the Gemini API, and view the results with the APS Viewer in a web page.

## Installation

### Client Setup

1. Navigate to the `client` directory:
    ```sh
    cd client
    ```

2. Install dependencies:
    ```sh
    npm i
    ```

3. Start the development server:
    ```sh
    npm run dev
    ```

### Dummy Server

1. In the `dummy server` directory, start the server:
    ```sh
    node server
    ```

## Features

- Upload `.iam` and `.ipt` files
- Animation generation using Gemini API
- View animations with APS Viewer in the browser
- Built with React (frontend)
- Styled using Tailwind CSS
- APS Viewer for rendering animations

## Tech Stack

- **Frontend:** React
- **Styling:** Tailwind CSS
- **Viewer:** APS Viewer
- **Backend:** Dummy Node.js server
